初次遇见Cola的十件小事

新用户最容易上手、马上能试的日常小事

01
整理一下桌面
桌面堆满了截图、PDF、安装包？让Cola按类型帮你归档。
  1. 跟Cola说"帮我整理一下桌面"
  2. Cola会先扫描有哪些文件，告诉你她打算怎么分类
  3. 你确认后她自动归档——图片、文档、安装包各归各位
  4. 原有的文件夹不会动
02
帮我查个东西，做个对比表
想对比几个产品/服务/方案的差异？说一句Cola就去查，还会自己纠错。
  1. 跟Cola说"帮我查一下XX和YY的区别"（比如几家云服务的价格）
  2. Cola自己去官网抓信息
  3. 查完说"做个对比表"，她直接生成整理好的表格
  4. 如果不放心，说"校核一下"，她会回去验证
03
放首歌
Cola接入网易云音乐后，说歌名就播，下一首、暂停、心动模式全一句话搞定。
  1. 跟Cola说"帮我接一下网易云音乐"
  2. Cola装好工具后引导你扫码登录
  3. 之后随时说"放首XX"就播放
  4. "下一首""暂停""每日推荐"都可以
04
帮我写封邮件
说清楚写给谁、关于什么，Cola帮你拟好，调调语气就能发。
  1. 跟Cola说"帮我写封邮件给XX，关于YY"
  2. 补充一些关键信息或你想表达的意思
  3. Cola会拟一版，你看看语气和内容
  4. 调整满意后复制发送
05
今天有什么安排
Cola帮你看日历、整理待办、提醒你接下来要做的事。
  1. 跟Cola说"帮我看看今天有什么安排"
  2. Cola读取你的日历和提醒事项
  3. 给你一份清晰的今日概览
  4. 你可以追加"帮我把XX加到日程里"
06
帮我做个PPT大纲
说清楚主题和受众，Cola帮你拉出结构，你再往里填内容。
  1. 跟Cola说"帮我做个PPT大纲，主题是XX，给YY看的"
  2. Cola会问几个关键问题（时长、重点、受众背景）
  3. 她拉出一份结构化大纲
  4. 你可以说"第三部分展开一下""加个案例"来调整
07
帮我总结这个文档
把一份长文档/PDF丢给Cola，她给你提炼要点。
  1. 把文件拖进Cola对话窗口
  2. 说"帮我总结一下重点"
  3. Cola会按结构提炼关键信息
  4. 你可以追问"第二章具体说了什么"
08
搭一个简单网页
想做个人主页/活动页/展示页？跟Cola说想要什么感觉就行。
  1. 跟Cola说"帮我搭一个XX页面"（个人主页/活动邀请页/产品展示页）
  2. 描述你想要的风格和内容
  3. Cola生成代码并预览给你看
  4. 调整满意后她直接部署上线
09
帮我想个选题/起个标题
写文章/发帖没灵感？Cola帮你头脑风暴，给方向不给废话。
  1. 跟Cola说"帮我想几个选题"或"帮我起个标题"
  2. 告诉她面向谁、什么平台、大概什么方向
  3. Cola给出几个方向+理由
  4. 你挑一个说"就这个，展开一下"
10
帮我填个表
申请表、注册表、报销单——Cola能从你之前的信息里自动填，不用重复输入。
  1. 打开要填的表单
  2. 跟Cola说"帮我填写这张表"
  3. Cola从你之前告诉她的信息+本地文件里提取
  4. 她填完让你确认，你检查一下提交

行业案例

按用户角色和行业，看Cola怎么帮到你

✍️
用Cola管理内容工作流
选题→写作→排版→发布，全流程用Cola协作。KOL用Cola搭建内容SOP，教客户直接用。
  1. 跟Cola说"帮我想几个选题"，告诉她你的账号定位和受众
  2. 选定方向后说"帮我写一篇"，Cola出初稿
  3. 你改完后说"帮我排版成小红书/公众号格式"
  4. 下次说"按上次的风格再来一篇"，Cola记得你的偏好
🚀
从填表到战略，Cola是我的参谋
Stripe申请表一句话填完、竞品调研自动跑、商业文档一起写。写代码之外的80%都交给她。
  1. 需要填表时跟Cola说"帮我填"，她从记忆和本地文件里提取信息
  2. 要调研时说"帮我查XX行业/竞品"，Cola自己去跑
  3. 写BP或商业文档时把想法丢给她，她帮你结构化
  4. 日常杂事（日程、邮件、文档整理）都一句话交给她处理
💼
一个人也能像一支队伍
写方案、做设计、整理SOP、管客户信息——以前需要助理做的事，现在Cola做。
  1. 把你的工作流程告诉Cola，她帮你整理成SOP
  2. 接到新项目时说"帮我写个方案"，描述客户需求
  3. 让Cola帮你管客户信息——"帮我整理一下最近的客户沟通记录"
  4. 重复性工作打包成Skill，下次一句话触发
🏢
把SOP教给Cola，让员工用
旅行社用Cola整理客户信息、生成攻略；团队把工作流程教给Cola，新人直接上手。
  1. 把团队的工作SOP教给Cola（直接发文档或口述）
  2. Cola学会后，团队成员可以直接问她"XX流程怎么走"
  3. 让Cola帮整理客户信息——"把最近一周的客户反馈汇总一下"
  4. 新人入职直接跟Cola学习业务流程，减少带教时间
🎓
从简历到面试，Cola帮我准备
改简历、模拟面试、整理行业信息、准备演讲——节省3小时起。
  1. 把简历发给Cola说"帮我优化一下"，告诉她目标岗位
  2. 说"帮我模拟面试"，Cola扮面试官提问+给反馈
  3. 准备演讲/答辩时说"帮我做个大纲"，Cola拉结构
  4. 跟Cola说"帮我追踪XX行业的招聘动态"，她定期给你更新
